# Dileep H — Portfolio

A responsive personal portfolio website for Dileep H.

## Included
- Responsive dark/glassmorphism design
- Home, About, Skills, Career Goals, Projects and Contact sections
- Mobile navigation
- Scroll reveal animations
- No frameworks required

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Personalize
1. Replace the photo placeholder in `index.html` with your own image.
2. Replace `your-email@example.com` with your real email.
3. Replace the GitHub and LinkedIn links with your profiles.
4. Update the Projects section as you complete real projects.

## Tech
HTML + CSS + JavaScript
